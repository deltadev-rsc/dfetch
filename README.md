# dfetch
My fetch on golang.

--------------------

# Build.
First, let's install the dependencies.

``` bash
# For arch
sudo pacman -S make go git
```

``` bash
# For void
sudo xbps-install -S make go git
```

``` bash
# For debian
sudo apt install make go git
```

Next, we clone the repository and build it.

``` bash
git clone https://github.com/deltadev-rsc/dfetch
cd dfetch
make run.
```
